# 实验、数据与证据教学

围绕当前段或图回答“作者要辨别什么，观测结果怎样回答这个问题”。下面的项目按研究类型选择，不做每图必填的长检查表。

## 方法：从问题解释设计

- 研究问题或假设是什么？为什么选这种实验、观察、模型或推导？
- 研究对象、实验单位、自变量/处理、因变量/指标、对照和条件是什么？比较主要排除了哪种其他解释？
- 样本量 n 指独立样本、受试者、批次还是技术重复？随机化、盲法、纳排和重复在原文中如何报告？没有报告的内容据实指出，不自行补齐。
- 样品经过哪些关键步骤变成数据？测量指标直接代表什么，只能间接推断什么？
- 从原始信号到最终图表经历哪些计算、归一化、拟合或统计步骤？这些步骤需要什么假设？
- 方法如何对应后文某张图和某个结论？必要时回查补充材料。

把方法解释成研究设计的依据与条件。用户希望借鉴时，说明可迁移的原理和仍需确定的条件；论文中简略的方法描述不自动构成完整、可直接执行的实验方案。

计算研究侧重数据划分、基线、评价指标、消融和外部验证；理论研究侧重定义、假设、推导及适用条件；定性研究侧重样本选择、资料收集、编码及论据与解释的关系。只使用适用的概念。

## 读图：看见什么，才解释什么

以一个面板为单元，先告诉用户这幅图要回答的问题，再带其读图：

1. **读懂编码。** 横纵轴、单位、线性/对数尺度、颜色/符号、分组、基线、图例和图注。表格则识别行列、单位、脚注和比较条件。
2. **描述观测。** 哪些组如何变化？关键差异、趋势、异常点是什么？正文或表格给出确切数值时引用并定位；从图中目测只说近似，不制造精度。由报告值计算的结果标注公式、输入和“据原文值计算”。
3. **解释分析。** 区分直接观测值、汇总量、拟合参数和统计检验。解释本文使用的检验或模型、适用假设、比较对象与报告结果。误差条是 SD、SEM 还是 CI，以图注/方法为准，未说明就记未说明。
4. **判断支持力度。** 看效应大小、变异/区间、样本量和对照。p 值不等于效应大小，也不是假设为真的概率；未显著不等于等效。统计显著性与科学或实际意义分别解释。
5. **回到主旨。** 概括“这张图支持的局部结论”，指出证据未能区分的解释，再接到全文主张。区分相关与因果、性能与机制、单一条件与普适性；需要时说清作者的措辞是否超出证据。

图、正文和图注出现冲突时并列记录位置与差异，围绕冲突继续核对方法或补充材料，不悄悄择一当正确答案。没有原始数据时可以解释作者的分析和检查报告值，但不能声称完成了重分析或复现。

## 用证据链代替结论堆砌

每一条关键主张用下面结构连接，标上原文位置：

> 问题 → 设计/对照 → 观测数据 → 分析方法 → 局部结论 → 主旨

例子仅演示推理，内容为教学假设：处理组均值高于对照组，只表明本条件下观测到组间差异；能否归因于处理，需要结合设计与混杂控制；能否解释机制，还要对应机制证据。不要将这个例子的结论写入论文事实笔记。

主旨串联也要保留反例、无差异结果和相互冲突的证据。对机制按“作者提出的解释—支持它的实验—尚未排除的替代解释”教学，避免把合理故事讲成已证实机制。

## 概念小课与理解检查

如果用户卡在统计、领域术语或公式，先用小例子讲概念，再回到图中同一处。检查问题贴近当下误解，例如：“这条误差条表示样本分散还是均值估计的不确定性？”“这一实验测的是机制本身，还是机制可能带来的现象？”

用户复述时，以原文和方法判断其解释。具体指出哪一步推理成立，哪一步需要额外证据，再让用户重述该连接。
