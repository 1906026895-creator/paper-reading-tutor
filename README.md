# 文献精读老师（paper-reading-tutor）

让 AI 像一位教学老师一样带你读论文：从文章地图开始，一次精读一个段落或图表，解释每句话为什么这样写、每段承担什么功能、实验如何产生数据、数据怎样支持结论，并通过复述帮助你真正理解文章。

这个 skill 面向“像学课文一样吃透文献”，适合基础知识还不完整、想读懂研究逻辑、需要学习实验设计，或希望提升论文写作能力的读者。

## 核心功能

### 1. 先建立文章地图

AI 会先梳理论文的研究问题、中心主张、章节职责和主要证据链，再进入逐段阅读。对于综述、理论、计算和定性研究，会按照论文自身的结构理解，不套用固定的实验论文模板。

### 2. 逐段解释句子和段落

每轮默认精读一个自然段或一个图表面板，重点回答：

- 这句话的字面意思是什么？
- 它在论证中承担什么功能？
- 为什么放在这里？和上下文是什么关系？
- 如果删掉这一段，全文会损失什么？
- 这一段如何服务文章主旨？

AI 会区分原文报告的事实、作者给出的解释，以及为了帮助理解而补充的知识或推演。

### 3. 把概念讲到真正懂

遇到难懂的术语、统计概念或公式时，按照以下顺序讲解：

> 通俗定义 → 直观例子或类比 → 必要的专业定义/公式 → 回到原文

解释公式时会说明符号、单位、假设和它在本文中的用途；类比会说明适用边界，避免把方便理解的例子误当成严格定义。

### 4. 串联实验、数据、分析和主旨

对于方法、结果和图表，AI 会解释：

- 研究要回答什么问题；
- 实验或分析如何设计，变量、对照、样本和数据来源是什么；
- 图表中实际观察到了什么；
- 使用了什么统计或模型分析；
- 这组证据支持哪个局部结论；
- 局部结论怎样连接到全文主张，以及证据的边界在哪里。

核心逻辑链是：

> 研究问题 → 研究设计/对照 → 观测数据 → 分析方法 → 局部结论 → 全文主旨

读图时还会关注坐标轴、单位、图例、误差条、样本量和统计量。无法从原文或图像确认的数值会明确标记，不补造数据。

### 5. 用提问检查是否真的理解

每个精读单元结束后，AI 会提出一个复述或迁移问题，例如：

- 这一段为什么接在上一段后面？
- 这组数据支持哪一步，不能支持哪一步？
- 如果去掉这个对照，还能做出同样的判断吗？
- 这个实验测量的是机制本身，还是机制可能产生的现象？

你回答后，AI 会保留正确部分，指出推理中断的位置，并用更小的步骤或例子补讲。你也可以直接说“继续”“换个例子”“给我答案”或“跳到 Figure 2”。

## 阅读目标

skill 支持根据不同目的调整路线：

| 阅读目的 | 重点路线 |
|---|---|
| 了解背景知识 | 摘要 → 结论 → 前言，按需查看结果与方法 |
| 把握研究方向 | 摘要 → 结论 → 前言 → 不足与展望，回查关键结果 |
| 学习课题设计 | 摘要/前言 → 结果与图表 → 材料与方法 → 结论 |
| 提升逻辑写作 | 摘要 → 前言，观察结果讨论的小标题、段首段尾和结论 |
| 像学课文一样吃透全文 | 全文逐段，联动方法、图表、补充材料和复述检查 |

如果还没有选定论文，skill 也可以根据标题、关键词和摘要帮助缩小范围，并判断一篇文章是否适合逐段精读。

## 笔记体系

模板位于 [阅读笔记模板](paper-reading-tutor/assets/reading-notes-template.md)，记录“文章写了什么、为什么这样写、我是否真正理解，以及我能借鉴什么”。

普通带读会在对话中记录进度。需要保存为文件时，可以明确提出下面的要求；AI 会按实际阅读进度创建或更新 Markdown 笔记，并保留你的原话与修正依据：

```text
请把目前读过的内容按笔记模板保存到当前工作区的 notes/论文精读笔记.md，
保留我的复述、你的纠错和未解决的问题，记录下次从哪里继续。
```

下次阅读时提供这份笔记和原文，让 AI 从记录的位置继续。

### 文章地图

记录研究背景、研究问题、中心主张、主要研究设计和章节/段落功能，先搭出全文框架。

### 段落功能笔记

每个已读段落记录：

- 位置和段首短语；
- 写了什么，关键句为何这样写；
- 承接上文、引出下文的方式；
- 实验、数据或引用证据；
- 如何服务文章主旨；
- 你的原话复述、AI 反馈和仍未解决的问题。

### 概念笔记

记录概念的原文术语和位置、通俗解释、专业含义、例子、类比边界、易混淆点，以及你自己的复述。这样下次回看时，能知道当时为什么卡住、后来如何理解。

### 实验与图表笔记

记录图表要回答的问题、变量、对照、实验单位、样本、数据来源、分析方法、关键观测值、误差条和统计量，并分别写下作者的解释、自己的理解、局部结论及证据边界。

### “125”学习成果

每篇文章尝试提炼：

- **1 个思路**：可以迁移到自己课题的研究或实验设计；
- **2 个图表**：值得学习的信息组织、形式或配色；
- **5 个句式**：记录原文位置、修辞功能、可迁移结构和自己的练习句。

数量是学习目标，材料不足时按实际完成数量记录，不为了凑数编写内容。

### 理解检查与续读

笔记会区分“AI 已经讲过哪些内容”和“你已经通过复述展示了哪些理解”。暂停时保存已读位置、下一单元、未解概念、待核对图表和理解状态，下一次可以直接继续。

## 安装

### 方式一：项目级（零配置，推荐）

克隆仓库，在仓库目录中启动 Claude Code 即可——`.claude/skills/` 下的 skill 会被自动加载，无需任何额外安装步骤：

```bash
git clone https://github.com/1906026895-creator/paper-reading-tutor.git
cd paper-reading-tutor
claude
```

如果想让 skill 在**另一个项目**中可用，把 skill 文件夹复制到该项目的 `.claude/skills/` 下：

```bash
cp -R .claude/skills/paper-reading-tutor <你的项目>/.claude/skills/
```

### 方式二：全局安装（所有项目可用）

把 skill 装到用户级技能目录 `~/.claude/skills/`，之后在任意项目中都能触发。**在任意目录**执行（无需先手动 clone 仓库）：

```bash
git clone https://github.com/1906026895-creator/paper-reading-tutor.git /tmp/paper-reading-tutor
mkdir -p ~/.claude/skills
cp -R /tmp/paper-reading-tutor/.claude/skills/paper-reading-tutor ~/.claude/skills/
```

如果已经按方式一 clone 过仓库，也可以直接进入仓库目录执行 `cp -R .claude/skills/paper-reading-tutor ~/.claude/skills/`，效果相同。

检查是否就位：

```bash
ls ~/.claude/skills/paper-reading-tutor
# 应看到 SKILL.md、assets/、references/
```

看到 `identical (not copied)` 提示说明该 skill 已经安装过，无需重复操作。更新 skill 时重新执行上面的 clone + `cp -R` 命令覆盖即可。

## 使用方法

### 在 Claude Code 中

按上文安装后，在对话中直接说明需求即可触发：

```text
带我精读这篇论文。我基础较弱，先给文章地图，再一次讲一段；遇到概念停下来解释，讲完让我复述。
```

也可以指定任务：

```text
讲解这篇论文的 Figure 2，重点解释实验设计、坐标轴、误差条、统计分析，以及这张图如何支持文章主旨。
```

### 在 Codex 中

```text
请使用 $paper-reading-tutor 带我精读这篇论文。我基础较弱，先给文章地图，再一次讲一段；遇到概念停下来解释，讲完让我复述。
```

也可以指定任务：

```text
请使用 $paper-reading-tutor 讲解这篇论文的 Figure 2，重点解释实验设计、坐标轴、误差条、统计分析，以及这张图如何支持文章主旨。
```

提供 PDF、正文、题名、DOI 或链接即可开始。只有摘要或片段时，AI 会先讲清可见内容，并标出需要全文才能确认的部分。

## 设计原则

- 逐段学习优先于一次性摘要。
- 原文事实、作者解释和教学补充分开记录。
- 证据不足时保留不确定性，不补造数值或实验结果。
- 用自己的话复述，才算完成理解检查。
- 笔记服务于后续阅读、写作、实验设计和知识迁移。
