# 阅读目的与筛选

## 按目的选材料和路线

用户的最终诉求优先于路线表；表中的略读不意味着可以忽略支撑关键结论的方法。

| 目的与阶段 | 优先材料 | 阅读路线与学习产出 |
|---|---|---|
| 背景入门：对主题陌生 | 相关硕博论文第一章综述，再读聚焦该问题的高质量综述 | 精读摘要→结论→前言，按需看结果与方法；形成概念关系和问题由来 |
| 把握方向：已有初步了解 | 近期研究及领域综述 | 摘要→结论→前言→讨论的不足与展望，追溯关键结果及必要方法；区分已解决、待验证和作者设想 |
| 学习设计：准备研究实践 | 本领域相关研究及可迁移的其他领域前沿论文 | 摘要和前言定位问题→结果/图表→方法→回查创新点与结论；提炼设计思路及适用条件 |
| 学习逻辑写作：任何阶段 | 论证清楚的优秀论文，包括顶刊论文 | 精读摘要→前言，查看结果/讨论小标题及段首段尾→结论；解释功能与衔接，提炼可迁移句式 |
| 全文吃透：默认目标 | 与课题相关、材料完整、值得细读的单篇论文 | 全文逐段，联动方法、图表与补充材料；理解概念，复述论证链 |

名家和期刊声誉可作选文线索；教学价值还取决于问题相关性、论证、方法透明度及材料可得性。将“这篇为什么好”落实到可观察优点，不推断编辑接受论文的真实原因。

## 缩小候选范围

1. 从用户课题提取研究对象、问题、方法及限制。信息不足而需要检索时，只问影响检索的关键项。
2. 依次看标题、关键词、摘要。缺少作者关键词时，用摘要中的对象和方法判断，不机械淘汰。
3. 核对摘要中的背景、目的、研究设计、主要发现和结论，说明与用户问题的具体关联。
4. 给少量候选及取舍理由：相关性、适合的阅读目的、先修知识、全文及图表可得性。默认优先选一篇开始，不先堆积大量下载。
5. 判断适合精读的程度：可以直接开始；补少量概念后开始；目前片段只适合局部阅读。论文重要但难度高时，先补基础再读。

“最新趋势”和“尚未实现”需要当前检索及足够文献支持；单篇论文的展望是线索，不能直接当作领域空白。跨领域迁移同时说明研究对象、尺度、数据条件、资源和评价指标是否相容。

## 用户提出工具需求时

- **文献鸟（Stork，https://www.storkapp.me/）**：可作为关键词文献提醒工具。解释怎样设计关键词；只有用户明确要求时才协助设置提醒，不因读论文自行创建订阅。
- **Connected Papers（https://www.connectedpapers.com/）**：以种子论文探索相关文献。其主图表达论文相似关系，不应直接称为逐条引用/被引关系；判断具体引用关系要核对参考文献或引用数据。
- 常见界面中，节点大小与引用量、颜色与发表时间、距离与相似性有关；具体颜色方向、边线粗细等以当前图例为准，不靠旧描述推断关系强弱。
- **Prior Works** 可帮助找到图中论文共同引用的较早工作，不自动等于学科开山之作；**Derivative Works** 可提示引用图中多篇论文的后续工作，其中可能有综述或相关研究。解释实际条目与种子论文的关系。
- **ReadPaper** 可按用户习惯用于笔记整理；无需为本技能额外注册或绑定工具。

## 学习写作时怎样讲

摘要逐句看“背景/缺口→目的/方法→结果→意义”的具体安排，不要求每篇都齐备或同序。前言追踪“已知→不足→本文问题与贡献”，解释引用和转折承担什么作用。结果与讨论看小标题、段首主张、证据组织、段尾回扣和跨段衔接。结论核对是否回答问题以及是否超出证据。

提炼五个句式时记录原文位置、修辞功能、可替换的结构和用户主题示例。研究事实保留在原论文中，迁移的是表达结构；示例中的假设内容明确标为练习。
